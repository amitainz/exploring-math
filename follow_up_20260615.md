Create a .tex worksheet, built as two-sided grid of 4 x 2 cells filling up the sheet (the grids are more of a 
general guide, you can merge cells as needed) 


the goal is to have a few kinds of exercises around the Euler discovery, each cell with its own exercise.

diagrams should be in the same design as the jurassic park diagram from the slide deck, but of course much simpler.

4 cells: Count posts, segments and regions in a given diagram. At least one example should have 4 posts.

4 cells: Try to create diagrams with given triplets of numbers (all possible) you can perhaps design things nicely 
so that there's one table with cells around it. If not each cell should have its own triplet of numbers clearly 
marked posts, segments and regions as in the final table in the slide deck.

4 cells: a table of triplets - some possible, some impossible. there's room to doodle, but the goal is to mark each 
row as possible or impossible (maybe add two columns with checkboxes, try to design it in a pleasing way)

4 cells: add your own examples, and count (leave room for drawing, add a table with multiple rows (6-7)
and 3 columns for the posts, segments and regions. Think of a nice way to make the matching of rows to drawings
explicit and easy (maybe label the rows with letters, or add lines connecting each row with a box?)


Zero region examples should not be the first ones, in either the given diagram case, or the given triplets case.
