 Teacher workflow

  1. Open the GitHub Pages deck URL.
  2. Set display mode to Extend, not Duplicate/Mirror.
     Windows: Win + P then Extend.
  3. Put the main deck window on the projector/display.
  4. Press S to open speaker view.
  5. Keep speaker view on the teacher laptop. It shows notes, current/next slide, elapsed timer, wall clock, and pacing.
  6. If a popup warning appears, allow popups for the GitHub Pages site.
  7. If the school only allows mirrored display, speaker notes are not workable: pupils will see the notes. Use printed/private notes instead.

  Do not use showNotes: true for classroom presenting; that puts notes into the public slide/PDF.

  Sources: Reveal speaker view docs say S opens notes, the speaker window includes timer/wall-clock/pacing, local use needs a web server, and notes are private in speaker
  view: https://revealjs.com/speaker-view/. DfE filtering/monitoring standards explain why school networks may block or monitor web content:
  https://www.gov.uk/guidance/meeting-digital-and-technology-standards-in-schools-and-colleges/filtering-and-monitoring-standards-for-schools-and-colleges.
